Process-engine architecture benchmark analysis
=============================================

Interpretation: c5000-X means 5000 process instances with X ms between instance starts. The -payload cases use a 10,000-byte instance payload. All measured times are milliseconds.
Measurement semantics: total = test start to end of the last instance; spawn = test start to end of spawning; drain = end of spawning until all instances are processed. Drain below 2000 ms is effectively zero for this measurement setup.
A drain above the measurement floor means processing is still outstanding after spawning has stopped; for a sustained arrival rate, this is evidence of backlog/overload.
Repetitions are aggregated by arithmetic mean; reported latency percentiles are therefore means of per-run percentiles.
